# 12306 购票助手 - 设计文档

## 概述

帮助用户查询 12306 火车票信息（直达 + 中转），按价格/耗时排序展示，支持查看车次详情和跳转官网购买的 Web 应用。

## 技术栈

- 前端: HTML + CSS + Vanilla JS
- 后端: Python + FastAPI + httpx
- 爬虫: httpx 直接请求 12306 API (`kyfw.12306.cn`)

## API 设计

### 1. 查询车次

```
POST /api/search
```

**请求参数:**

```json
{
  "from":    "北京",
  "to":      "上海",
  "date":    "2026-05-20",
  "sort_by": "price"
}
```

- `sort_by`: `price` 按价格 | `duration` 按时长 | `departure` 按出发时间。默认 `price`

**返回结构:**

```json
{
  "from": "北京",
  "to": "上海",
  "date": "2026-05-20",
  "direct": [
    {
      "train_no": "G1",
      "from_station": "北京南",
      "to_station": "上海虹桥",
      "depart_time": "09:00",
      "arrive_time": "13:28",
      "duration": "4h28m",
      "seats": [
        { "type": "二等座", "price": 626 },
        { "type": "一等座", "price": 1035 }
      ],
      "buy_link": "https://kyfw.12306.cn/otn/leftTicket/init?...",
      "actions": {
        "detail": "/api/train/G1?date=2026-05-20",
        "buy_link": "https://kyfw.12306.cn/otn/leftTicket/init?..."
      }
    }
  ],
  "transfers": [
    {
      "segments": [
        {
          "train_no": "G1",
          "from_station": "北京南",
          "to_station": "南京南",
          "depart_time": "09:00",
          "arrive_time": "12:30",

```

**错误码:**

| 场景 | HTTP | 返回 |
|------|------|------|
| 12306 不可达 | 503 | `{"error": "查询服务暂不可用，请稍后重试"}` |
| 查询无结果 | 404 | `{"error": "未找到该线路的车次", "direct": [], "transfers": []}` |
| 参数非法 | 400 | `{"error": "参数格式错误"}` |
| 频率超限 | 429 | `{"error": "操作太频繁", "retry_after": 60}` |

### 交互行为

- "查看详情": 网页内展开/收起经停站列表，不跳转
- "去官网购买": 新标签页打开 12306 购买页，参数已预填
- 排序切换: 平滑过渡动画
- 车次卡片: 悬停上浮 + 阴影加深
- 加载态: 骨架屏
- 错误态: 友好提示 + 重试按钮

## 智能交互

- 站名模糊匹配 + 别名识别
- 输入 2 字触发下拉建议
- 日期选择器禁用过去日期，默认明天
- 直达/中转一键切换
- 直达无结果自动搜索中转
- 完全无结果提示拆段查询或换日期
- 价格最低标注「💡最实惠」、耗时最短标注「⚡最快」
- 换乘 < 30 分钟标黄警告、< 15 分钟标红
- 售罄席别灰显「已售罄」
- 最近 5 次查询本地保存

## 鲁棒性

| 场景 | 处理 |
|------|------|
| 出发/到达为空 | 标红抖动，提示必填 |
| 站名不识别 | 下拉建议最近匹配 |
| 日期为过去 | 置灰不可选，重置为明天 |
| 重复点击查询 | 按钮置灰 + 加载态 |
| 查询超时 (15s) | 中断，提示重试 |
| 12306 不可达 | 降级提示 + 缓存 |
| 风控拦截 | 60s 倒计时提示 |
| 数据格式异常 | 前端校验不崩溃 |
| 网络断开 | 检测并提示，恢复后重连提示 |
| 后端宕机 | 友好提示 + 状态说明 |
| 结果缓存 | 相同查询 2min 内走缓存 |

## 安全防护

### 后端

- 速率限制: 同 IP 每分钟最多 10 次
- 输入校验: 站名只允许中文/英文/数字，长度 ≤20
- 请求体 ≤ 1KB
- CORS 白名单（仅 localhost）
- 安全响应头 (移除 Server/X-Powered-By)
- 错误不泄露堆栈
- 异常 IP 自动封禁 30 分钟

### 前端

- XSS: DOM 操作使用 textContent + DOMPurify
- 链接白名单: 仅允许 `*.12306.cn`
- CSP: 限制脚本同源加载
- X-Frame-Options: DENY

### 12306 请求

- UA 随机轮换
- 请求间隔 ≥ 3s
- Cookie 隔离（独立 Session）
- HTTPS 强制 + 证书验证

### 部署

- 敏感配置存 `.env`
- `pip audit` 检查依赖漏洞
- 进程不以 root 运行
- 日志脱敏

## 数据流

```
前端输入 (from/to/date/sort)
    ↓
POST /api/search (FastAPI main.py)
    ↓
crawler.py → httpx → 12306 API (直达)
    ↓
route_planner.py → 枚举中间站 → crawler.py → 12306 API (分段)
    ↓
合并、排序、返回 JSON
    ↓
前端渲染列表
    ↓
用户选择 → 新窗口打开 12306 购买页
```
